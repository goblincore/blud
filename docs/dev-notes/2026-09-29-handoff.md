## Things a new agent must know

- **Gates pin looks with explicit params.** march-hash and the disco/train gates boot `?layers=all`; the light gate
  boots every layer but `sCurve` (its bounds predate it). Keep that when editing boot URLs. `LIGHT_LAYERS=` overrides.
- **march-hash pins moved with Chrome, not code** (153 → 154 auto-update, 2026-09-28 19:41). New pins d7392d52 /
  0c71e712 / 470ff0b3. Before bisecting a moved pin, check the Chrome version
  (`defaults read "/Applications/Google Chrome.app/Contents/Info.plist" CFBundleShortVersionString`).
- **Cost gates need a quiet machine:** close the owner's game tabs (they ran ~380% CPU and produced false over-budget
  fails at load 7–25). Load average under 4.
- **Headless capture gotchas:** treat a missing `window.__warmGate` as NOT ready (cold compiles show the loader);
  step once more before shooting (the torch pool lags a placement); never set the light clock back before the
  torch's switch-on (it reads as off).
- **Level pipeline:** build `kit.blend` IN PLACE (a kit saved elsewhere loses its 42 textures on export).
- **The zombie has a TS twin** (`body.ts` `makeZombie`) pinned to `zombie.blob` by `zombie-blob.test.ts`; its rig now
  has 19 points (toes). Changing the zombie's body regenerates the gib assets (`npm run gib:assets`).
- Useful seams: `layers()`, `setLayer(k, on)`, `bodyListLanes()`, `setListLook({...})`, `setContrast(k, pivot)`,
  `actorGround(id)`.
