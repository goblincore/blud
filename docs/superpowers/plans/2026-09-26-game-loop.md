# The game loop (refresh of Wake Plan 2) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The SDF FPS becomes a game on authored levels: health, damage (zombie bites, the bride's sword, soldier pellets and cultist rounds), death and restart, pickups and loadout, finite ammo, trigger events, gates, level completion. Night Train is the test level.

**Architecture:** Three pure modules hold the rules (`player-vitals.ts`, `pickups.ts`, `level-events.ts`), as written in [Wake Plan 2](2026-09-11-wake-2-game-loop.md) Tasks 1–3 (code there, with the defaults below). The wiring lives in a leaf module, `game-loop-leaves.ts`, with its state on the `player` and `world` slices (the plan template's rule), not in `main()` locals; `game-main.ts` only calls it.

**Tech Stack:** TypeScript, vitest, three r186, CDP gate.

**Owner (2026-09-26):** "for now just make some defaults you think are okay and we can tweak from there".

## Changes from Wake Plan 2 (verified against today's code)

- **Zombies never report melee contact** (`game-main.ts`: "the zombie mind never reports contact"); only the bride's sword mind does. Zombie damage is a **bite by proximity**: a live (not collapsed) zombie within `VITALS.biteReach` of the player bites, rate-limited by the melee invulnerability window. Frozen AI (`__sdfGame.freeze(true)`) never bites.
- **The bride's `onMeleeContact`** already drives `hitFeedback` (flash and shake); it now also damages.
- **Cultist SMG rounds** share `ctx.weapon.soldierPellets` with soldier pellets; one capsule test covers both.
- **Weapon slots** are `shotgun | dynamite | flare` (`game-weapon-slots.ts`); there is no melee weapon yet. `loadout: ["melee"]` owns nothing selectable, so Night Train starts **empty-handed** until the sawn-off (a few metres from the start). Unowned weapons can't be selected or fired, and the viewmodel hides while the live slot is unowned.
- **Test level:** Night Train (`completeOn` defaults to `pickup.cd`: the CD in the jukebox ends the level). The Wake keeps working.
- **State** on slices: `player.vitals`, `player.inventory`; `world.takenPickups`, `world.triggerState`, `world.pendingEvents`, `world.levelDone`, `world.pickupMeshes` (binding-count tests updated).
