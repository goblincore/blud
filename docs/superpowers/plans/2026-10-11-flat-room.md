# The Flat's Room in the Engine Implementation Plan

> **For agentic workers:** implement task-by-task. Steps use checkbox (`- [ ]`) syntax. Tasks 5–7, 9 and 11 end in a
> screenshot the owner judges; stop at each milestone marker (end of Tasks 8, 10 and 13) and show the images before going on.

**Goal:** a walkable `?level=flat`: the last-stage room from the 2026-10-01 look-dev (stone shell, Giger layer, hero props), built by a
Blender script and exported through the existing level route.

**Spec:** `docs/superpowers/specs/2026-10-11-flat-room-design.md` — read it first. **Look-dev source to port:**
`docs/dev-notes/2026-10-01-flat-room-lookdev/room.py` (1418 lines; line numbers below are for that file).

**Architecture:** the room is authored in Blender by `scripts/levels/build_the_flat.py`, which calls three builder modules
(`flat/shell.py`, `flat/giger.py`, `flat/props.py`) ported from `room.py`. Every number they share lives in `scripts/levels/flat_layout.py`.
Cycles node materials are replaced by plain glTF PBR materials (`flat/materials.py`) over textures generated by
`flat/make_textures.py`. `export_level.py` writes `flat.level.json` + `flat.art.glb`, both committed. The only engine edits are a
menu entry and tests.

**Tech Stack:** Blender 5.2 (`/opt/homebrew/bin/blender`, headless), Python 3 with Pillow and numpy, Vitest, headless-Chrome capture scripts.

## Rules for every task

- Work only in this worktree (`claude/flat-room`). Never `git stash`. `node_modules` is symlinked: do not reinstall.
- **Targeted tests only** (`npx vitest run <path>`, or `npm run test:changed`) plus `npm run typecheck`. Never the full suite locally; CI runs it.
- **Headless capture only** (the in-app browser pane loses the WebGPU device). Scripts own their own vite + Chrome via
  `scripts/lab-servers.sh` and must use their own port pair (`LAB_VITE_PORT=5560 LAB_CDP_PORT=9560`). Set `LAB_TMP=.lab-tmp`.
- **Prove visual and performance claims with a number and look at the images yourself.**
- Never commit extracted Blood assets. This plan commits only authored files: scripts, generated textures, the level export.
- Blender gotchas from the look-dev: an object name ending in a long float after a dot aborts Blender (format numbers in names);
  bone pitches over 90° do not take (irrelevant here); lights inside an opaque shade light nothing.
- Space: the scripts work in Blender space (x, y, z), z up, north (the window) is +y. Game space is (x, z, -y).
- **Exporter rules** (`scripts/levels/export_level.py`): every `dressing` mesh has exactly one material; objects are joined per room and
  material (draw calls follow the material count); textures are at most 1024 px; only MESH objects export (convert curves).

## Port rules (apply to every task that copies from `room.py`)

1. Copy the listed line range into the new module, inside a `build(M)` function (or module-level helpers where the task says so).
2. Replace `M_NAME` with `M.NAME` (names in Task 3's table). A material the table lacks means the code is clutter: drop that call.
3. Delete every `point_light(...)`, `area_light(...)` and `camera(...)` call: lights are in `flat_layout.LIGHTS`.
4. Replace `sc.collection.objects.link(x)` with `C.dressing().objects.link(x)` (the `common.py` helpers already do).
5. Any `obj_from_bm(name, bm, [m1, m2], ...)` with a list of materials is split into one object per material.

```python
# scripts/levels/flat_layout.py
"""The Flat's room: every number the build script, the texture script and the tests share.

Blender space (x, y, z), z up. North (the window wall) is +y. Game space is (x, z, -y).
Pure python: importable from Blender and from plain python3. `python3 scripts/levels/flat_layout.py` runs the self-check.
Dimensions are the 2026-10-01 look-dev's (docs/dev-notes/2026-10-01-flat-room-lookdev/room.py, lines 213-224).
"""
import math

X0, X1, Y0, Y1 = -1.35, 1.35, 0.0, 3.6          # six tatami: 2.7 m wide, 3.6 m long
SPRING = 1.95                                   # the vault springs from the side walls here
RV = 1.8                                        # the vault's radius
CZ = SPRING - math.sqrt(RV * RV - X1 * X1)      # the vault circle's centre height
CROWN = CZ + RV                                 # about 2.56 m
FLOOR = 0.055                                   # top of the tatami (the room box's floor is z 0)
RIBS = (0.9, 1.8, 2.7)                          # transverse ribs; the middle one is the vertebral (Giger) rib

WX, WH, WS, WSP, WDEPTH = 0.12, 0.36, 0.62, 1.42, 0.62   # window: centre x, half width, sill z, springing z, wall thickness
KX, KY, KTOP = 0.12, 2.36, 0.44                 # kotatsu: centre and board top
NICHE = (2.42, 3.12, 0.92, 1.62)                # west wall niche: y0, y1, z0, z1
SH_X0, SH_Y0, SH_Y1, SH_H = X1 - 0.27, 1.55, 2.95, 1.55   # the bookshelf (east wall)


def vault_z(x):
    return CZ + math.sqrt(max(0.0, RV * RV - x * x))


# Each wall's texture covers WALL_W[name] x WALL_H metres, starting at WALL_U0[name] along the wall (x for n/s, y for e/w).
WALL_H = 2.7
WALL_W = {"n": X1 - X0 + 0.2, "s": X1 - X0 + 0.2, "e": Y1 + 0.2, "w": Y1 + 0.2}
WALL_U0 = {"n": X0 - 0.1, "s": X0 - 0.1, "e": Y0 - 0.1, "w": Y0 - 0.1}
# Wet and rust runs (room.py 432-446): (u along the wall in metres from the texture's left edge, z, spread, length, strength).
STAINS = {
    "n": [(WX - 0.32 - X0 + 0.1, WS - 0.08, 0.05, 0.55, 0.9), (WX + 0.32 - X0 + 0.1, WS - 0.08, 0.05, 0.5, 0.8),
          (-1.0 - X0 + 0.1, 1.6, 0.06, 0.75, 0.9), (0.74 - X0 + 0.1, 0.5, 0.04, 0.4, 0.8),
          (X1 - 0.12 - X0 + 0.1, 2.2, 0.08, 1.5, 1.0), (0.0 - X0 + 0.1, 2.42, 0.1, 1.0, 0.9)],
    "e": [(3.3 + 0.1, 1.15, 0.07, 0.4, 1.0), (3.2 + 0.1, 1.9, 0.05, 0.6, 0.8), (Y1 - 0.12 + 0.1, 2.0, 0.07, 1.4, 1.0),
          (0.5 + 0.1, 1.9, 0.05, 0.9, 0.6)],
    "w": [(2.3 + 0.1, 1.8, 0.06, 1.7, 1.0), (2.77 + 0.1, 0.88, 0.1, 0.5, 0.6), (1.0 + 0.1, 1.9, 0.05, 0.8, 0.5)],
    "s": [],
}

# The player starts at the south end, facing the window (yaw 0 faces +y here, -z in game space).
START = (0.12, 0.55, 0.0)                       # x, y, z (z is the floor)

# Collision boxes ("furniture"): name -> ((minx, miny, minz), (maxx, maxy, maxz)).
ROOM_BOX = ((X0, Y0, 0.0), (X1, Y1, round(CROWN, 3)))
COLLISION = {
    # The engine's capsule steps up onto a box lower than about 0.5 m (least-penetration push-out), so the kotatsu's collider is
    # taller than its board: the player cannot climb the table. The futon stays low on purpose: a cushion you walk over.
    "kotatsu": ((KX - 0.41, KY - 0.41, 0.0), (KX + 0.41, KY + 0.41, 0.9)),
    "futon": ((-1.325, 0.3, 0.0), (-0.475, 2.2, 0.15)),
    "fridge": ((-1.29, 3.04, 0.0), (-0.79, 3.56, 0.92)),
    "counter": ((0.79, 3.07, 0.0), (1.35, 3.59, 0.83)),
    "shelf": ((SH_X0, SH_Y0, 0.0), (X1, SH_Y1, SH_H)),
}

# Point lights: (name, position, colour, power, extra custom properties). Powers are starting values, tuned in Task 8.
LIGHTS = [
    ("window", (WX, Y1 - 0.25, 1.4), (0.62, 0.74, 0.90), 3.0, {"fixture": "none"}),         # the only cool light (no shadow: the format allows it on tube fixtures only)
    ("lantern", (0.0, 1.05, CROWN - 0.62), (1.0, 0.36, 0.20), 2.0, {"fixture": "none"}),
    ("candle", (X0 + 0.14, 2.05, 1.53), (1.0, 0.65, 0.35), 1.0, {"fixture": "none"}),
    ("amber", (KX, KY + 0.14, 0.75), (1.0, 0.62, 0.20), 1.6, {"fixture": "none"}),                    # where the iMac will sit
]


def inside(p, box, pad=0.0):
    (a, b) = box
    return all(a[i] - pad <= p[i] <= b[i] + pad for i in range(3))


def check():
    assert abs(CROWN - 2.559) < 0.005, CROWN
    assert inside(START, ROOM_BOX), "start outside the room"
    for name, box in COLLISION.items():
        assert inside(box[0], ROOM_BOX, 1e-6) and inside(box[1], ROOM_BOX, 1e-6), f"{name} leaves the room"
        assert not inside(START, box), f"start is inside {name}"
    assert WX - WH > X0 and WX + WH < X1, "window outside the north wall"
    assert WSP + WH < vault_z(WX), "window arch hits the vault"
    for name, pos, col, power, _ in LIGHTS:
        assert inside(pos, ROOM_BOX), f"light {name} outside the room"
        assert all(0 <= c <= 1 for c in col) and power > 0
    for k, w in WALL_W.items():
        assert 1.0 < w <= 4.0
        for u, z, spread, length, strength in STAINS[k]:
            assert 0 <= u <= w and 0 <= z <= WALL_H, (k, u, z)
    print("flat_layout: ok")


if __name__ == "__main__":
    check()
```

```ts
// scripts/levels/flat-textures.test.ts
//
// The Flat's generated textures exist and obey the exporter's 1024 px limit.

// @ts-expect-error — node:fs available in vitest
import { existsSync, readFileSync } from 'node:fs';
import { describe, expect, it } from 'vitest';

const DIR = 'assets-source/levels/flat-textures';
const STONES = ['wall_n', 'wall_e', 'wall_w', 'wall_s', 'vault', 'flag', 'dark'];
const FILES = [...STONES.flatMap(s => [`${s}_color.jpg`, `${s}_normal.jpg`]), 'tatami.jpg', 'quilt.png', 'books.png', 'view.jpg'];

/** Width and height of a PNG (IHDR) or a JPEG (the first start-of-frame marker). */
function imageSize(file: string): [number, number] {
  const b = readFileSync(`${DIR}/${file}`);
  if (b.readUInt32BE(0) === 0x89504e47) return [b.readUInt32BE(16), b.readUInt32BE(20)];
  let i = 2;
  while (i < b.length) {
    const marker = b[i + 1];
    if (marker >= 0xc0 && marker <= 0xcf && marker !== 0xc4 && marker !== 0xc8 && marker !== 0xcc) return [b.readUInt16BE(i + 7), b.readUInt16BE(i + 5)];
    i += 2 + b.readUInt16BE(i + 2);
  }
  throw new Error(`${file}: no JPEG frame header`);
}

describe('flat textures', () => {
  it('every texture exists', () => {
    for (const f of FILES) expect(existsSync(`${DIR}/${f}`), f).toBe(true);
  });
  it('none is over 1024 px on a side', () => {
    for (const f of FILES) {
      const [w, h] = imageSize(f);
      expect(Math.max(w, h), f).toBeLessThanOrEqual(1024);
    }
  });
  it('a stone colour and its normal are the same size', () => {
    for (const s of STONES) expect(imageSize(`${s}_color.jpg`)).toEqual(imageSize(`${s}_normal.jpg`));
  });
});
```

```python
# scripts/levels/flat/make_textures.py
"""Textures for the Flat. Plain python3 (Pillow, numpy), not Blender:

    python3 scripts/levels/flat/make_textures.py

Writes PNGs of 1024 px or less into assets-source/levels/flat-textures/ (the exporter refuses larger).
Stone colour and normal come from the kit's baked Bryce rock (assets-source/levels/kit-textures/rock-color.png, one tile = 1 m)
and the wet and rust runs of the look-dev's stain maps (docs/dev-notes/2026-10-01-flat-room-lookdev/room.py 228-253).
PNG row 0 is the TOP of the image (the highest z).
"""
import os
import subprocess
import sys

import numpy as np
from PIL import Image

HERE = os.path.dirname(os.path.abspath(__file__))
sys.path.insert(0, os.path.join(HERE, ".."))
import flat_layout as L  # noqa: E402

ROOT = os.path.abspath(os.path.join(HERE, "..", "..", ".."))
ROCK = os.path.join(ROOT, "assets-source/levels/kit-textures/rock-color.png")
LOOKDEV = os.path.join(ROOT, "docs/dev-notes/2026-10-01-flat-room-lookdev")
IDYLL = os.path.join(ROOT, "docs/dev-notes/2026-10-01-flat-emergence-lookdev/view-bryce-moody.png")
OUT = os.path.join(ROOT, "assets-source/levels/flat-textures")
CASTLE = np.array((1.6, 1.55, 1.45), np.float32)       # the baked rock is dark; castle stone a step lighter (room.py 266)


def save(arr, name):
    """PNG, or JPEG for `.jpg` names: the embedded art file stays small, and 4:4:4 keeps a normal map's channels clean."""
    os.makedirs(OUT, exist_ok=True)
    im = Image.fromarray((np.clip(arr, 0, 1) * 255).astype(np.uint8))
    if name.endswith(".jpg"):
        im.save(os.path.join(OUT, name), quality=90, subsampling=0)
    else:
        im.save(os.path.join(OUT, name))
    print("wrote", name, arr.shape[1], "x", arr.shape[0])


def rock():
    return np.asarray(Image.open(ROCK).convert("RGB"), np.float32) / 255.0


def lin(c):
    """sRGB to linear light: the look-dev's colour maths (tints, mixes) ran in linear, so ours does too."""
    return np.power(c, 2.2)


def srgb(c):
    return np.power(np.clip(c, 0, 1), 1 / 2.2)


def tile_to(img, w_m, h_m, px):
    """The 1 m rock tile repeated to cover w_m x h_m metres in a px x px image (anisotropic when w_m != h_m)."""
    tw, th = max(1, round(px / w_m)), max(1, round(px / h_m))
    tile = np.asarray(Image.fromarray((img * 255).astype(np.uint8)).resize((tw, th), Image.LANCZOS), np.float32) / 255.0
    return np.tile(tile, (int(np.ceil(px / th)), int(np.ceil(px / tw)), 1))[:px, :px]


def smooth_noise(px, cells, seed):
    g = np.random.default_rng(seed).random((cells + 1, cells + 1)).astype(np.float32)
    return np.asarray(Image.fromarray((g * 255).astype(np.uint8)).resize((px, px), Image.BICUBIC), np.float32) / 255.0


def stain_map(w_m, h_m, sources, seed, ppm=200):
    """Wet (R) and rust (G) runs down a wall, in z-up rows (row 0 = z 0). Ported from room.py 228-253, then resized."""
    W, H = int(w_m * ppm), int(h_m * ppm)
    img = np.zeros((H, W, 2), np.float32)
    rnd = np.random.default_rng(seed)
    for (u, z, spread, length, strength) in sources:
        for _ in range(int(40 * spread / 0.1) + 8):
            x = int((u + rnd.normal(0, spread)) * ppm)
            top = int((z + rnd.normal(0, 0.03)) * ppm)
            run = int(length * ppm * rnd.uniform(0.3, 1.0))
            wpx = int(rnd.integers(1, 4))
            rust = rnd.uniform(0.0, 1.0)
            for yy in range(max(0, top - run), min(H, top)):
                t = (top - yy) / max(run, 1)
                a = strength * (1 - t) ** 1.5 * rnd.uniform(0.6, 1.0)
                x0, x1 = max(0, x - wpx), min(W, x + wpx)
                if x0 < x1:
                    img[yy, x0:x1, 0] = np.maximum(img[yy, x0:x1, 0], a)
                    img[yy, x0:x1, 1] = np.maximum(img[yy, x0:x1, 1], a * rust)
                x += int(rnd.integers(-1, 2)) if rnd.random() < 0.08 else 0
        yy, xx = np.mgrid[0:H, 0:W]
        d = np.sqrt(((xx / ppm - u) / (spread * 2.5)) ** 2 + ((yy / ppm - z) / (spread * 2.0)) ** 2)
        img[..., 0] = np.maximum(img[..., 0], strength * 0.6 * np.clip(1 - d, 0, 1))
    k = 3                                                   # soften across the run (room.py 249-251)
    for c in (0, 1):
        cs = np.cumsum(np.pad(img[..., c], ((0, 0), (k, k)), mode="edge"), axis=1)
        img[..., c] = (cs[:, 2 * k:] - cs[:, :-2 * k]) / (2 * k)
    return img


def normal_from_height(h, strength):
    """Tangent-space normal (OpenGL, +green up) from a height field whose row 0 is the top."""
    gy, gx = np.gradient(h)
    n = np.dstack((-gx * strength, gy * strength, np.ones_like(h)))
    n /= np.linalg.norm(n, axis=2, keepdims=True)
    return n * 0.5 + 0.5


def make_stone(name, w_m, h_m, px=1024, tint=(1.0, 1.0, 1.0), courses=None, stains=None, damp=True, seed=0):
    """name_color.jpg and name_normal.jpg: castle stone over a w_m x h_m metre area (z up, row 0 the top)."""
    base = tile_to(rock(), w_m, h_m, px)
    col = np.clip(lin(base) * np.array(tint, np.float32) * CASTLE, 0, 1)
    height = base.mean(axis=2)
    zz = (1.0 - (np.arange(px)[:, None] + 0.5) / px) * h_m * np.ones((1, px), np.float32)      # metres above the base
    xx = (np.arange(px)[None, :] + 0.5) / px * w_m * np.ones((px, 1), np.float32)
    if courses:
        bw, bh = courses
        row = np.floor(zz / bh)
        fx = ((xx + (row % 2) * bw * 0.5) / bw) % 1.0
        fy = (zz / bh) % 1.0
        d = np.minimum.reduce([fx * bw, (1 - fx) * bw, fy * bh, (1 - fy) * bh])               # metres to the nearest mortar line
        mortar = np.clip(1.0 - d / 0.012, 0, 1)
        col = col * (1 - 0.9 * mortar[..., None]) + mortar[..., None] * np.array((0.03, 0.028, 0.025), np.float32) * 0.9
        height = height - 0.6 * mortar
    if damp:
        dz = np.clip((0.55 - zz) / 0.5, 0, 1) * 0.75 * (0.3 + 0.7 * smooth_noise(px, 12, seed + 7))
        col = col * (1 - dz[..., None]) + dz[..., None] * np.array((0.025, 0.032, 0.018), np.float32)
    if stains:
        st = stain_map(w_m, h_m, stains, seed)
        st = np.stack([np.asarray(Image.fromarray(st[..., c]).resize((px, px), Image.BICUBIC), np.float32) for c in (0, 1)], axis=2)
        st = np.flipud(st)                                                                     # z-up rows -> PNG rows
        rust, wet = st[..., 1:2], st[..., 0:1] * 0.85
        col = col * (1 - rust) + rust * np.array((0.2, 0.075, 0.02), np.float32)
        col = col * (1 - wet) + wet * np.array((0.018, 0.016, 0.01), np.float32)
    save(srgb(col), f"{name}_color.jpg")
    save(normal_from_height(height, 6.0), f"{name}_normal.jpg")


def make_tatami(px=512):
    """Aged igusa straw: fine weave lines (one tile is 0.9 m), faded green-gold (room.py 327-342)."""
    n = smooth_noise(px, 8, 3)[..., None]
    col = np.array((0.24, 0.20, 0.08), np.float32) * (1 - n) + np.array((0.42, 0.40, 0.18), np.float32) * n
    u = (np.arange(px)[None, :] / px * 90) % 1.0
    line = (np.abs(u - 0.5) * 2) ** 3 * 0.55
    col = col * (1 - line[..., None]) + line[..., None] * np.array((0.16, 0.13, 0.05), np.float32)
    save(srgb(col * np.ones((px, 1, 1), np.float32)), "tatami.jpg")


def make_quilt(px=512):
    """The kawaii quilt: the look-dev's own tile if textures.py runs here (it wants Hiragino for the posters), else a plain pink one."""
    tmp = os.path.join(ROOT, ".lab-tmp", "flat-quilt")
    os.makedirs(tmp, exist_ok=True)
    subprocess.run([sys.executable, os.path.join(LOOKDEV, "textures.py"), tmp], check=False, capture_output=True)
    src = os.path.join(tmp, "quilt.png")
    if os.path.exists(src):
        arr = np.asarray(Image.open(src).convert("RGB").resize((px, px), Image.LANCZOS), np.float32) / 255.0
    else:
        yy, xx = np.mgrid[0:px, 0:px] / px
        dots = (np.sin(xx * 6.283 * 6) * np.sin(yy * 6.283 * 6) > 0.6).astype(np.float32)[..., None]
        arr = np.array((0.95, 0.72, 0.8), np.float32) * (1 - dots) + dots * np.array((1.0, 0.95, 0.97), np.float32)
    save(arr, "quilt.png")


def make_books():
    """An 8-stripe palette (room.py SPINES, 1209-1215 neighbourhood): a book's UVs point at its stripe."""
    pal = [(0.85, 0.1, 0.15), (0.1, 0.25, 0.7), (0.95, 0.8, 0.2), (0.15, 0.6, 0.35), (0.95, 0.95, 0.92), (0.1, 0.1, 0.12),
```

```python
# scripts/levels/flat/common.py
"""Blender helpers for the Flat's builders. Ported from docs/dev-notes/2026-10-01-flat-room-lookdev/room.py 49-212.

Everything is created in the `dressing` collection (the exporter's art). One material per object (the exporter's rule).
Run inside Blender.
"""
import math

import bmesh
import bpy
from mathutils import Matrix, Vector  # noqa: F401  (re-exported for the builders)


def collection(name):
    c = bpy.data.collections.get(name)
    if c is None:
        c = bpy.data.collections.new(name)
        bpy.context.scene.collection.children.link(c)
    return c


def dressing():
    return collection("dressing")


def use_dressing():
    """Make `dressing` the active collection so bpy.ops.mesh.primitive_* create objects in it."""
    target = dressing()

    def find(lc):
        if lc.collection is target:
            return lc
        for ch in lc.children:
            r = find(ch)
            if r:
                return r
        return None

    bpy.context.view_layer.active_layer_collection = find(bpy.context.view_layer.layer_collection)
    return target


def world_box_uv(obj, size=1.0):
    """Box-projected UVs from world positions: one tile = `size` metres (a number or an (x, y, z) tuple)."""
    bpy.context.view_layer.update()
    me = obj.data
    if not me.uv_layers:
        me.uv_layers.new(name="UVMap")
    uv = me.uv_layers.active.data
    sx, sy, sz = (size, size, size) if isinstance(size, (int, float)) else size
    mw = obj.matrix_world
    rot = mw.to_3x3()
    for poly in me.polygons:
        n = rot @ poly.normal
        ax = max(range(3), key=lambda i: abs(n[i]))
        for li in poly.loop_indices:
            p = mw @ me.vertices[me.loops[li].vertex_index].co
            uv[li].uv = {0: (p.y / sy, p.z / sz), 1: (p.x / sx, p.z / sz), 2: (p.x / sx, p.y / sy)}[ax]


def planar_uv(bm, axis, u0, w_m, h_m):
    """UVs for a wall built in world coordinates: u along the wall ('x' or 'y'), v up; the wall's texture covers w_m x h_m from u0 at z 0."""
    uvl = bm.loops.layers.uv.verify()
    k = 0 if axis == "x" else 1
    for f in bm.faces:
        for l in f.loops:
            p = l.vert.co
            l[uvl].uv = ((p[k] - u0) / w_m, p[2] / h_m)


def rand_uv(bm, layer, n):
    """Each face's UVs collapse to the middle of stripe int(rand * n) of an n-stripe palette (books.png)."""
    uvl = bm.loops.layers.uv.verify()
    for f in bm.faces:
        u = (min(n - 1, int(f[layer] * n)) + 0.5) / n
        for l in f.loops:
            l[uvl].uv = (u, 0.5)


def obj_from_bm(name, bm, material, smooth=False, bevel=0.0, segs=2, uv_size=1.0):
    me = bpy.data.meshes.new(name)
    has_uv = bool(bm.loops.layers.uv)
    bm.to_mesh(me)
    bm.free()
    o = bpy.data.objects.new(name, me)
    dressing().objects.link(o)
    me.materials.append(material)
    if smooth:
        for p in me.polygons:
            p.use_smooth = True
    if not has_uv and uv_size:
        world_box_uv(o, uv_size)
    if bevel:
        b = o.modifiers.new("bev", "BEVEL")
        b.width = bevel
        b.segments = segs
        b.limit_method = "ANGLE"
    return o


def bm_cube(bm, c, s, rot=None, layer=None, val=0.0):
    M = Matrix.Translation(Vector(c)) @ (rot.to_4x4() if rot is not None else Matrix.Identity(4)) @ Matrix.Diagonal((s[0], s[1], s[2], 1))
    r = bmesh.ops.create_cube(bm, size=1.0, matrix=M)
    for f in {f for v in r["verts"] for f in v.link_faces}:
        if layer is not None:
            f[layer] = val
    return r["verts"]


def _finish(o, material, uv_size):
    o.data.materials.append(material)
    if uv_size:
        world_box_uv(o, uv_size)
    return o


def box(name, c, s, material, bevel=0.0, rot=(0, 0, 0), uv_size=1.0):
    bpy.ops.mesh.primitive_cube_add(size=1, location=c, rotation=rot)
    o = bpy.context.active_object
    o.name = name
    o.scale = s
    bpy.ops.object.transform_apply(scale=True)
    if bevel:
        b = o.modifiers.new("bev", "BEVEL")
        b.width = bevel
        b.segments = 3
        b.limit_method = "ANGLE"
    return _finish(o, material, uv_size)


def cyl(name, c, r, d, material, rot=(0, 0, 0), verts=24, r2=None, smooth=True, uv_size=1.0):
    if r2 is None:
        bpy.ops.mesh.primitive_cylinder_add(radius=r, depth=d, location=c, rotation=rot, vertices=verts)
    else:
        bpy.ops.mesh.primitive_cone_add(radius1=r, radius2=r2, depth=d, location=c, rotation=rot, vertices=verts)
    o = bpy.context.active_object
    o.name = name
    if smooth:
        bpy.ops.object.shade_smooth()
    return _finish(o, material, uv_size)


def sphere(name, c, r, material, scale=(1, 1, 1), seg=24, rot=(0, 0, 0), uv_size=1.0):
    bpy.ops.mesh.primitive_uv_sphere_add(radius=r, location=c, segments=seg, ring_count=max(3, seg // 2), rotation=rot)
    o = bpy.context.active_object
    o.name = name
    o.scale = scale
    bpy.ops.object.shade_smooth()
    return _finish(o, material, uv_size)


def torus(name, c, R, r, material, rot=(0, 0, 0), scale=(1, 1, 1), uv_size=1.0):
    bpy.ops.mesh.primitive_torus_add(major_radius=R, minor_radius=r, location=c, rotation=rot, major_segments=32, minor_segments=12)
    o = bpy.context.active_object
    o.name = name
    o.scale = scale
    bpy.ops.object.shade_smooth()
    return _finish(o, material, uv_size)


def tube(name, pts, radii, material, res=4, cyclic=False):
    """A beveled curve, converted to a mesh (the exporter only takes meshes)."""
    cu = bpy.data.curves.new(name, "CURVE")
    cu.dimensions = "3D"
    cu.bevel_depth = 1.0
    cu.bevel_resolution = res
    cu.use_fill_caps = True
    sp = cu.splines.new("NURBS")
    sp.points.add(len(pts) - 1)
    sp.use_endpoint_u = not cyclic
    sp.use_cyclic_u = cyclic
    sp.order_u = min(4, len(pts))
    for i, (p, r) in enumerate(zip(pts, radii)):
        sp.points[i].co = (p[0], p[1], p[2], 1.0)
        sp.points[i].radius = r
    ob = bpy.data.objects.new(name, cu)
    ob.data.materials.append(material)
    dressing().objects.link(ob)
    bpy.context.view_layer.update()
    for o in bpy.context.view_layer.objects:
        o.select_set(False)
    ob.select_set(True)
    bpy.context.view_layer.objects.active = ob
    bpy.ops.object.convert(target="MESH")
    return bpy.context.view_layer.objects.active


def catmull(pts, n_per=12):
    """Sample a Catmull-Rom spline through pts: returns [(pos, tangent)]."""
    P = [Vector(p) for p in pts]
    P = [P[0] * 2 - P[1]] + P + [P[-1] * 2 - P[-2]]
    out = []
    for i in range(1, len(P) - 2):
        p0, p1, p2, p3 = P[i - 1], P[i], P[i + 1], P[i + 2]
        for k in range(n_per):
            t = k / n_per
            pos = 0.5 * ((2 * p1) + (-p0 + p2) * t + (2 * p0 - 5 * p1 + 4 * p2 - p3) * t * t + (-p0 + 3 * p1 - 3 * p2 + p3) * t ** 3)
            tan = 0.5 * ((-p0 + p2) + 2 * (2 * p0 - 5 * p1 + 4 * p2 - p3) * t + 3 * (-p0 + 3 * p1 - 3 * p2 + p3) * t * t)
            out.append((pos, tan.normalized()))
    out.append((P[-2], (P[-2] - P[-3]).normalized()))
    return out


def resample(samples, step):
    """Even arc-length spacing along sampled spline points."""
    res = [samples[0]]
    acc = 0.0
    for (a, ta), (b, tb) in zip(samples, samples[1:]):
        seg = (b - a).length
        acc += seg
        while acc >= step:
            acc -= step
            t = 1 - acc / seg if seg > 0 else 1
            res.append((a.lerp(b, t), ta.lerp(tb, t).normalized()))
    return res


def smoothstep(e0, e1, x):
    t = max(0.0, min(1.0, (x - e0) / (e1 - e0)))
    return t * t * (3 - 2 * t)
```

```python
"""The Flat's materials: plain glTF-exportable PBR (Principled BSDF over image textures), replacing room.py's Cycles node trees.

`make()` returns a namespace M; builders use M.STONE_N etc. Textures come from assets-source/levels/flat-textures/ (make_textures.py).
Emission is capped at 1 by the engine (ART_EMISSIVE_CAP), so emissive materials use strength 1.
Run inside Blender.

import os
from types import SimpleNamespace

import bpy

TEX = os.path.abspath("assets-source/levels/flat-textures")


def _image(nt, file, color=True):
    t = nt.nodes.new("ShaderNodeTexImage")
    t.image = bpy.data.images.load(os.path.join(TEX, file), check_existing=True)
    t.image.colorspace_settings.name = "sRGB" if color else "Non-Color"
    t.extension = "REPEAT"
    return t


def pbr(name, color=(0.5, 0.5, 0.5), rough=0.8, metal=0.0, tex=None, normal=None, normal_strength=1.0, emit=None, emit_tex=None):
    """color: (r, g, b); tex/normal: file names in TEX; emit: (r, g, b) at strength 1; emit_tex: a file shown as emission."""
    m = bpy.data.materials.new(name)
    m.use_nodes = True
    nt = m.node_tree
    p = nt.nodes["Principled BSDF"]
    p.inputs["Base Color"].default_value = (*color, 1.0)
    p.inputs["Roughness"].default_value = rough
    p.inputs["Metallic"].default_value = metal
    if tex:
        nt.links.new(_image(nt, tex).outputs["Color"], p.inputs["Base Color"])
    if normal:
        nm = nt.nodes.new("ShaderNodeNormalMap")
        nm.inputs["Strength"].default_value = normal_strength
        nt.links.new(_image(nt, normal, color=False).outputs["Color"], nm.inputs["Color"])
        nt.links.new(nm.outputs["Normal"], p.inputs["Normal"])
    if emit_tex:
        p.inputs["Base Color"].default_value = (0, 0, 0, 1)
        nt.links.new(_image(nt, emit_tex).outputs["Color"], p.inputs["Emission Color"])
        p.inputs["Emission Strength"].default_value = 1.0
    elif emit:
        p.inputs["Emission Color"].default_value = (*emit, 1.0)
        p.inputs["Emission Strength"].default_value = 1.0
    return m
```

```python
"""The stone shell: walls, vault, ribs, window, floor (Task 5 and 6 replace this skeleton)."""
import bmesh

import flat_layout as L
from flat import common as C


def quad(bm, a, b, c, d):
    return bm.faces.new([bm.verts.new(v) for v in (a, b, c, d)])


def build(M):
    x0, x1, y0, y1, z1 = L.X0, L.X1, L.Y0, L.Y1, L.CROWN
    for key, mat, face in (("n", M.STONE_N, lambda b: quad(b, (x0, y1, 0), (x1, y1, 0), (x1, y1, z1), (x0, y1, z1))),
                           ("s", M.STONE_S, lambda b: quad(b, (x1, y0, 0), (x0, y0, 0), (x0, y0, z1), (x1, y0, z1))),
                           ("e", M.STONE_E, lambda b: quad(b, (x1, y1, 0), (x1, y0, 0), (x1, y0, z1), (x1, y1, z1))),
                           ("w", M.STONE_W, lambda b: quad(b, (x0, y0, 0), (x0, y1, 0), (x0, y1, z1), (x0, y0, z1)))):
        bm = bmesh.new()
        face(bm)
        C.planar_uv(bm, "x" if key in "ns" else "y", L.WALL_U0[key], L.WALL_W[key], L.WALL_H)

    bm = bmesh.new()
    quad(bm, (x0, y0, 0), (x1, y0, 0), (x1, y1, 0), (x0, y1, 0))
    C.obj_from_bm("floor", bm, M.FLAG, uv_size=1.8)
    bm = bmesh.new()
    quad(bm, (x0, y0, z1), (x0, y1, z1), (x1, y1, z1), (x1, y0, z1))
    C.obj_from_bm("ceiling", bm, M.VAULT, uv_size=1.0)
```
